English summary

KonaklamaFlow is an open-source, privacy-first fictional offline hospitality operations prototype. This integrated release candidate combines a precomputed reservation review, source-bound evidence display, synthetic benchmark scorecard and fictional decision history. These are not proof of live deployment, real staff actions or independently verified hotel accuracy: 7/10 project-authored cases are evaluated. The bounded room allocation proposal solver is Python-only and is not connected to the UI. No live PMS, OTA, KBS, AI provider or payments are connected.

KonaklamaFlow · MIT açık kaynak · GitHub · PR bağlantıları tarihçe ve kaynak kodudur; canlı yayın durumunu GitHub Actions üzerinden kontrol et. Gerçek kişi veya otel kaydı kullanılmaz.
