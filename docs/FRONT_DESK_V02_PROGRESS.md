# KonaklamaFlow front-desk operations (v0.2 development)

An independent, privacy-first check-in readiness prototype is under development. This branch is experimental and must not be used for live check-in, KBS, payments, or guest identity processing.

Planned components: deterministic arrival checklists, housekeeping and maintenance checks, offline read-only cockpit, and an expiring second-assistant review contract. Real PMS connections require separate authorization, security review, and human approval.
