### Technical and accessibility safeguards / Teknik ve erişilebilirlik korumaları

- The landing page uses local `<picture>` GIFs and **static posters for `prefers-reduced-motion: reduce`**. Animated visuals have substantive alternate text and are lazy-loaded.
- No remote image fetch, external script, active network AI service, embedded guests, customer records or hotel credentials.
- Only specifically reviewed relative GIF/JPG assets are copied into GitHub Pages staging via `scripts/stage_demo_site.py`; staged content must pass offline release preflight and browser checks.
- Real demo recordings and future vision illustrations are **visually separated and individually labeled** in both English and Turkish, including visible limitations.

### Important credibility boundary / Kanıt sınırı

Public operator-review evidence is documented separately in [the first-party hotel assessment](OPERATOR_FIRST_PARTY_REVIEW_2026-11-15.md) and [its privacy-redacted PDF scans](evidence/KonaklamaFlow_Operator_Review_PUBLIC_REDACTED_TR_EN_2026-11-15.pdf). **Concept GIFs have no evidentiary value for hotel validation and are not part of the signed operator review.**
