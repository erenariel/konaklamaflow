# KonaklamaFlow — fictional operator feedback / kurgusal operatör testi

We welcome practical feedback from hotel reception, housekeeping and finance staff **without uploading actual records**. Türkçe ya da İngilizce geri bildirim kabul edilir.

## Five-minute offline evaluation / Beş dakikalık değerlendirme

1. Open the [public fictional demo](https://erenariel.github.io/konaklamaflow/) or download the [standalone HTML](../demo/v04-integrated-preview.html). Use only the preloaded example records.
2. **Reservation conflict / Rezervasyon çakışması:** Identify the reservation with conflicting inventory. Can you see *which rule*, *what evidence* and *what human approval* are needed?
3. **Room plan / Oda planı:** Follow a fictional booking to the room rack. Can you distinguish held, out-of-order, housekeeping and available rooms? Never treat a draft suggestion as a promise.
4. **Daily handover / Vardiya devri:** Find the next-day arrivals and distinguish review-ready tasks from actions needing staff verification. Was the reason understandable?
5. **Language / Dil:** Switch to one other language. Note any untranslated or overflowing text and the browser/viewport.

## What to report / Ne paylaşmalı?

- Screen and action: e.g., `Overview → AI explanation → Room plan`.
- Fictional sample reference only: e.g., `DEMO_RES_01`, not an actual OTA or PMS confirmation number.
- What you expected, what you observed, and one concrete improvement.
- Optional, voluntary timing: how long it took to locate a conflict **in the demo**. Do not invent productivity claims or compare with real guests.
- The demo version/commit if known.

Open a [new feedback issue](https://github.com/erenariel/konaklamaflow/issues/new/choose) using **Operator feedback (fictional data only)**. Suggestions can also be contributed through [CONTRIBUTING.md](../CONTRIBUTING.md).

## Never submit / Kesinlikle paylaşma

Real guest names, personal identifiers, passports, hotel account IDs, private internal rates, screenshots containing guest records, API credentials, proprietary PMS databases, employee data or live hotel incident logs. **Changing the letters of a real confirmation code is not sufficient anonymization.**

## What feedback is not / Ne anlama gelmez?

A completed test of the demo is not permission to access an operational hotel system, and a self-reported opinion is not evidence that the product is deployed. Independent uptake/pilot studies will only be reported after actual consent and verifiable review.
